# Diamonds VPN — redesign concept

A live coded **concept** redesign of the Diamonds VPN landing page (a VPN sold inside Telegram and paid with TON). Not affiliated with or endorsed as the official product site; the product itself is no longer active.

Design and art direction: Oleksandr Chykhaiev. Built with AI-assisted coding (Claude).

- `index.html`: the deployed site, a single self-contained file (Three.js, GSAP, Lenis bundled in).
- `source/`: readable source (`src/hero.js`, `src/field.js`, `src/roamer.js`, `src/main.js`, `src/style.css`) and the build scripts.
- `vercel.json`: security headers (CSP, HSTS, framing limited to the portfolio, noindex).
